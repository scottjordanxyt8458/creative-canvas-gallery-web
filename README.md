## Getting Started

First, clone the repository and enter its project directory:

```bash
git clone https://github.com/scottjordanxyt8458/creative-canvas-gallery-web.git
cd creative-canvas-art-gallery
```

Basic viewing does not require package installation. You can open the primary HTML file directly in a browser, or use a local server to serve the project directory.

To start one with Python, run:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser after the server starts.
